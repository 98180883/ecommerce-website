
🛒 Fully Functional Frontend E-Commerce Website

A fully functional, multi-page frontend e-commerce website built with HTML, CSS, and JavaScript. Features include a hamburger menu, SEO-friendly structure, and a smooth shopping experience — all on the frontend

✨ Features

🏷️ Product Catalog – Browse and view multiple products

🛍️ Shopping Cart – Add, remove, and update items

🍔 Hamburger Menu – Responsive navigation for mobile & desktop

🔍 Search Functionality – Quickly find products

📄 Multi-Page Layout – About , Home, Products,Contact page ,login & sign-up pages

💾 Persistent Cart – Cart saved with LocalStorage

📱 Clean UI & Modern Design – Attractive and professional look.

🎨 Responsive Design – Works perfectly on desktop, tablet, and mobile.

📊 SEO Friendly – Proper meta tags and semantic HTML

⚡ Performance Optimization – Lazy loading, image compression for faster load times.


🛠️ Technologies Used:

HTML5 – Semantic structure for SEO

CSS3 – Styling and fully responsive design

JavaScript (ES6+) – For functionality


🚀 How to Run

Clone or download the repository:

git clone https://github.com/98180883/ecommerce-website.git

Open index.html in your browser to start exploring.
